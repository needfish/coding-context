# Modeling Communication

- State what a model preserves and what it omits.
- Use precise identifiers for distinct entities.
- State the limitations of explanations and models.
- Show how the conclusion was arrived at.
- Contextualize recommendations: "for a prototype this is fine" versus "for production, prefer X."
- State trade-offs explicitly. Choose practical solutions. Propose minimal experiments.

Use ontological modeling for stable domains with formal standards. Use problem-focused modeling for novel problems and rapid prototyping. Use iterative change-driver grouping for long-lived systems with evolving requirements.
